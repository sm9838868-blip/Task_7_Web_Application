📌 Overview

This project demonstrates hands-on web application security testing performed in a controlled environment using a deliberately vulnerable application. The goal is to identify common vulnerabilities, understand how they are exploited, and document appropriate mitigation techniques.
The testing aligns with OWASP Top 10 principles and focuses on practical exposure rather than production exploitation. �

🎯 Objectives

Understand how common web vulnerabilities occur
Learn how attackers exploit insecure implementations
Practice identifying and validating vulnerabilities
Document findings with impact and remediation steps

🛠 Tools Used

Burp Suite (Community Edition) – Intercepting and analyzing HTTP requests
OWASP Juice Shop – Deliberately vulnerable web application
Web Browser – Chrome / Firefox

🧪 Application Tested

Name: OWASP Juice Shop
Type: Intentionally vulnerable web application
Environment: Localhost (safe testing setup)

🔍 Methodology

Studied OWASP Top 10 vulnerabilities
Configured Burp Suite as an intercepting proxy
Captured and analyzed HTTP requests and responses
Performed manual testing for common vulnerabilities
Documented payloads, impacts, and mitigations
